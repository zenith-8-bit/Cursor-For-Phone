# Example tasks

Start with simple navigation.

### 1. Home

```text
Open the home screen.
```

### 2. Search

```text
Open Amazon and search for black hoodies.
```

### 3. WhatsApp

```text
Open WhatsApp and open the chat with Alice.
```

### 4. Missing information

```text
Send a WhatsApp message to Alice saying I will be late.
```

If Alice is ambiguous or a required detail is missing, the agent should ask rather than guess.

### 5. Multi-step

```text
Open Chrome, search for Android AccessibilityService,
and open the first relevant result.
```

Keep the first experiments within 5–9 actions.
